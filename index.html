Apa yang ingin kamu lakukan?

Pilih cara masuk. Workspace lokal yang sudah tersimpan tidak akan diubah sampai kamu memilih aksinya.

State dan file lokal tetap berada di perangkat atau browser yang kamu pilih. Memuat save file dari perangkat lain tidak menghapus file asli.

Cara kerja EnviroTrack

Jangan mulai dari portal. Mulai dari konteks.

EnviroTrack menyusun data kegiatan menjadi gambaran kerja yang lebih mudah dibaca. Basis regulasi tetap bersifat umum. Konteks proyek hanya dipakai ketika kamu ingin melihat aturan dan pekerjaan yang terpicu.

Mulai atau lanjutkan

Pilih cara masuk ke workspace.

Mulai dari formulir kosong, lanjutkan workspace lokal, atau load save file dan bundle ZIP dari perangkat lain.

Alat bantu penapisan dan pengelolaan pekerjaan lingkungan.
